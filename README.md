# Pacific Defender

Browser anti-aircraft game set from Pearl Harbor to Okinawa. You man period U.S. Navy guns — Browning .50, 20 mm Oerlikon, 40 mm Bofors, and the 5"/38 — against Zeros, Vals, Kates, Judys, Bettys, and Ohkas.

Original work. Not affiliated with *Pearl Harbor: Defend the Fleet*.

## Run

```bash
npm install
npm run dev
```

Open the local dev server, then **Start campaign** or **Gunnery range**.

Mouse aims, click or Space fires, 1–4 selects guns, Shift or right mouse zooms, R reloads, Esc pauses.
